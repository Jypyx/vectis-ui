# IconButton

Bouton à icône seule : un wrapper de `Button` rendu **carré** (largeur = hauteur, padding
supprimé), avec la même API visuelle. La prop `label` est **obligatoire** — elle pose
l'`aria-label` du bouton, car une icône seule ne fournit aucun nom accessible aux lecteurs
d'écran.

L'icône peut être fournie de deux façons : par la prop `icon` (nom d'icône ou rendu explicite, sans
passer par le slot — le remplissage se pilote alors via `icon-filled`), ou dans le slot par
défaut pour du contenu custom (le slot ne s'affiche qu'en l'absence de `icon`). Via le
composant `Icon`, la taille et l'axe `opsz` suivent automatiquement la taille du bouton
(xs → 16px, sm/md → 20px, lg/xl → 24px).

## Variants et tones

Mêmes cinq variants (`solid`, `outline`, `ghost`, `elevated`, `tonal`) et cinq tones
(`accent`, `neutral`, `danger`, `success`, `warning`) que `Button` — voir sa documentation
pour le détail de chaque rendu. Défauts adaptés à l'usage icône : `variant="ghost"` et
`tone="neutral"` (l'IconButton est typiquement une action discrète de barre d'outils).

<Canvas of={IconButtonStories.Variants} />

## Tailles

Cinq tailles carrées (`xs` 24px, `sm` 32px, `md` 40px, `lg` 48px, `xl` 56px) ; `compact`
réduit le côté de 4px (20/28/36/44/52px) sans changer la taille de l'icône. La largeur suit
automatiquement la hauteur du `Button` sous-jacent, compact inclus.

<Canvas of={IconButtonStories.Sizes} />

## Icône par prop

La prop `icon` prend un nom d'icône (ou un rendu explicite) et rend l'`Icon` en interne, sans
passer par le slot ; `icon-filled` demande la variante pleine (axe `FILL`).

<Canvas of={IconButtonStories.IconProp} />

## Sources d'icône

Le slot (fallback en l'absence de `icon`) accepte les trois sources du composant `Icon` :
SVG embarqué du DS, ligature de la police du consommateur (voir le README), SVG inline, ou
image.

## Accessibilité

- `label` obligatoire → `aria-label` : le bouton a toujours un nom accessible ; l'icône,
  elle, reste décorative (`aria-hidden`).
- Pour un bouton avec libellé visible **et** icône, utiliser `Button` avec
  `icon-start`/`icon-end` plutôt qu'un IconButton.
- Focus visible par anneau (`--vectis-focus-ring-*`), transitions soumises à
  `prefers-reduced-motion` — hérités de `Button`.
