# Toast

Notifications triggered **programmatically**: mount `<VToaster />` once (at the app root), then
call `toast(options)` from anywhere — a component, a store, an asynchronous API return. The queue
is reactive state at module level (no provide/inject); it is **client-only**: never call `toast()`
during SSR rendering.

```vue
<!-- App.vue -->
<VToaster placement="bottom-right" :duration="5000" />
```

```ts
import { toast, dismissToast } from 'vectis-ui'

async function save() {
  try {
    await api.save()
    toast({ tone: 'success', message: 'Changes saved.' })
  } catch {
    toast({ tone: 'danger', title: 'Error', message: 'The server is not responding.', duration: 0 })
  }
}
```

The display goes through the Popover API: one `popover="manual"` **per placement** carries the
stack (the native top layer, no z-index), and the stacking is pure CSS — the JavaScript is limited
to the queue → `showPopover()`/`hidePopover()` bridge and to the auto-dismiss timers.

## Tones

Five tones × two variants. `soft` (the default): a `-surface` background, a `-border` border, a
tinted icon and title. The `neutral` tone rests on `surface-overlay`.

<Canvas of={VToasterStories.Tones} />

`solid`: the tone's full colour. `warning` uses `--vectis-color-text-on-warning` (dark text, white
fails AA on amber); `neutral` switches to an inverted contrast (`surface-inverse`, tooltip style),
readable in both themes.

<Canvas of={VToasterStories.Solid} />

## Placements

Six screen positions, in independent stacks. The VToaster's `placement` prop sets the default; a
toast's `placement` option overrides it. **Physical** coordinates (`top/left`…): a notification is
a screen position, independent of the reading direction — like the OS notifications.

<Canvas of={VToasterStories.Placements} />

## Display duration

`duration` (a VToaster prop: 5000 ms by default, overridable per toast) drives the automatic
dismissal. Hovering a stack **suspends its timers**; they restart at the full duration when the
pointer leaves (WCAG 2.2.1).

<Canvas of={VToasterStories.AutoDismiss} />

`duration: 0` makes the toast persistent: it stays until dismissed through the cross (a `close`
VIconButton, hideable through `closable: false`) or by `dismissToast(id)`.

## Icons

Each tone has its default Material Symbols icon: `notifications` (neutral), `info` (accent),
`check_circle` (success), `error` (danger), `warning` (warning). The `icon` option accepts any icon
name or an explicit render (`{ src }`, as everywhere else); `icon: false` removes it. The tone
icons are embedded SVGs: they display with no font at all (see VIcon).

<Canvas of={VToasterStories.CustomIcon} />

## Width

Default width: the `--vectis-control-size-toast-width` token (22rem). The `width` option (a CSS
length) replaces it per toast — always bounded by `100vw − margins`, so a toast never overflows the
viewport.

<Canvas of={VToasterStories.Width} />

## Stacking

The toasts of a given placement stack up, the most recent near the screen edge (pure CSS
`column`/`column-reverse`, the queue staying append-only). The entry slides in from the edge
through `@starting-style`; the individual exit is not animated (a simplicity choice), and the stack
emptying fades out.

<Canvas of={VToasterStories.Stacking} />

## Accessibility

- Role per toast: `role="alert"` (interruptive) for `danger`/`warning`, `role="status"` (polite)
  otherwise — the announcement of a stack's first polite toast may be missed by some screen readers
  (the live region is born with its content); `alert`s are announced on insertion.
- Each stack is a `role="region"` landmark named by the `label` prop ("Notifications"); the cross
  receives `closeLabel` ("Close").
- The focus is never stolen: a toast appears without interrupting the current input.
- Timers pause on hover; the animations respect `prefers-reduced-motion`.

This component's accessible labels come from the design system dictionary: they translate globally
(see **Foundations › Internationalization**), and the text props stay authoritative for a
case-by-case adjustment.
