# IconButton

Icon-only button: a wrapper around `VButton` rendered **square** (width = height, padding
removed), with the same visual API. The `label` prop is **mandatory** — it sets the button's
`aria-label`, because an icon alone gives screen readers no accessible name.

The icon can be provided in two ways: through the `icon` prop (an icon name or an explicit
render, without going through the slot — the fill is then driven by `icon-filled`), or in the
default slot for custom content (the slot only shows when `icon` is absent). Through the `VIcon`
component, the size and the `opsz` axis automatically follow the button size (xs → 16px,
sm/md → 20px, lg/xl → 24px).

## Variants and tones

The same five variants (`solid`, `outline`, `ghost`, `elevated`, `tonal`) and five tones
(`accent`, `neutral`, `danger`, `success`, `warning`) as `VButton` — see its documentation for
the detail of each rendering. The defaults suit icon usage: `variant="ghost"` and
`tone="neutral"` (a VIconButton is typically a discreet toolbar action).

<Canvas of={VIconButtonStories.Variants} />

## Sizes

Five square sizes (`xs` 24px, `sm` 32px, `md` 40px, `lg` 48px, `xl` 56px); `compact` reduces the
side by 4px (20/28/36/44/52px) without changing the icon size. The width automatically follows
the height of the underlying `VButton`, compact included.

<Canvas of={VIconButtonStories.Sizes} />

## Icon through a prop

The `icon` prop takes an icon name (or an explicit render) and renders the `VIcon` internally,
without going through the slot; `icon-filled` asks for the filled variant (the `FILL` axis).

<Canvas of={VIconButtonStories.IconProp} />

## Icon sources

The slot (the fallback when `icon` is absent) accepts all three sources of the `VIcon`
component: the DS's embedded SVG, a ligature from the consumer's font (see the README), inline
SVG, or an image.

## Accessibility

- A mandatory `label` → `aria-label`: the button always has an accessible name; the icon itself
  stays decorative (`aria-hidden`).
- For a button with a visible label **and** an icon, use `VButton` with `icon-start`/`icon-end`
  rather than a VIconButton.
- Visible focus through a ring (`--vectis-focus-ring-*`), transitions subject to
  `prefers-reduced-motion` — both inherited from `VButton`.
