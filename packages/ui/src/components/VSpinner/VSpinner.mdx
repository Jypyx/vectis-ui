# Spinner

Indicateur de chargement **100 % CSS** : un cercle animé (`border` + rotation), sans SVG ni
JavaScript. La racine porte `role="status"` avec un libellé masqué visuellement — annoncé par
les lecteurs d'écran sans bruit visuel.

<Canvas of={SpinnerStories.Default} />

<Controls of={SpinnerStories.Default} />

## Taille

**1em par défaut** : le spinner suit la taille du texte environnant ; un parent peut aussi le
dimensionner en posant `font-size` sur son conteneur (c'est ce que font `Button`, `Input` et
`Textarea`, qui le calent sur la taille de leurs icônes). La prop `size` (nombre, en pixels)
permet une surcharge libre : `:size="32"` → 32px. L'épaisseur du cercle est proportionnelle
(⅛ de la taille : 2px à 16px, 3px à 24px).

<Canvas of={SpinnerStories.Tailles} />

## Couleur

Le cercle suit `currentcolor` : il hérite de la couleur de texte du parent, sans prop dédiée.

<Canvas of={SpinnerStories.Colore} />

## Accessibilité

- `role="status"` + libellé masqué (`label`, défaut « Chargement… ») : l'état est annoncé
  par les lecteurs d'écran ; personnaliser le libellé selon le contexte (« Envoi en
  cours… »).
- Le cercle animé est `aria-hidden` : seul le libellé porte l'information.
- `prefers-reduced-motion` ralentit fortement la rotation au lieu de la supprimer :
  l'information « ça charge » reste perceptible.
- Dans `Button`, `Input` et `Textarea`, le composant parent gère l'annonce (`aria-busy`,
  libellé dédié) — le spinner y est purement visuel.

Les libellés accessibles de ce composant viennent du dictionnaire du design system : ils se traduisent globalement (voir **Fondations › Internationalisation**), et les props texte restent prioritaires pour un ajustement au cas par cas.
