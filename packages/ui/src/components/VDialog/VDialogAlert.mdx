# DialogAlert

The alert variant of `VDialog`: **the same design**, but with `role="alertdialog"` — a modal that
**requires an explicit action** from the user (a destructive confirmation, a loss of data…). It is
a plain `VDialog` wrapper that locks the semantics down and **cuts off every light dismiss**: no
cross, no backdrop click, **no Escape key** (`closedby="none"`). Only the footer buttons close the
modal.

## Why a wrapper

`VDialogAlert` forces `role="alertdialog"`, `hideClose`, `persistentBackdrop` and
`persistentEscape` on `VDialog`. All the machinery (the top layer, the focus trap, the inert
background, the sticky header/footer, the scroll separators, the lazy mounting) is inherited as it
is — there is no point duplicating the component. The default width is `400px` (the `width` prop).

## Accessibility

- `role="alertdialog"` signals a modal interrupting the flow and awaiting an answer — screen
  readers announce it accordingly.
- `title`/`subtitle` feed `aria-labelledby`/`aria-describedby`.
- No "accidental" exit: no cross, no backdrop, no Escape. **Always** provide at least one explicit
  close button in the `#footer` slot (a "Cancel", for instance), or the modal would be a dead end.
- The focus trap and the focus return to the trigger stay provided by `showModal()`.
