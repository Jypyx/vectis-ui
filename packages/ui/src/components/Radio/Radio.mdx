# Radio

Bouton radio construit sur l'`<input type="radio">` natif, visuellement remplacé par une
pastille stylée (même approche que `Checkbox` : l'input reste dans l'arbre, seul son rendu est
masqué). Le groupe est **natif** : plusieurs Radio partageant le même `name` (fallthrough) et
le même v-model — la navigation aux flèches est fournie par le navigateur, zéro JavaScript.

Taille unique : pastille de 20px, bordure de 2px (tokens `--ds-control-size-check` et
`--ds-control-border-width`), point intérieur de 8px (`--ds-control-size-check-dot`).

<Controls of={RadioStories.Groupe} />

Chaque Radio porte une prop `value` ; le v-model du groupe vaut la `value` du bouton
sélectionné.

## Position du libellé

`label-position` place le libellé après (`end`, défaut) ou avant (`start`) la pastille.

<Canvas of={RadioStories.PositionDuLibelle} />

## Spread

`spread` fait passer la racine en flex pleine largeur : libellé et pastille sont repoussés aux
extrémités du conteneur. Se combine avec `label-position` pour choisir de quel côté part la
pastille.

<Canvas of={RadioStories.Spread} />

## États

`disabled` bascule la pastille sur des nuances de gris (`--ds-color-surface-muted`,
`--ds-color-text-subtle`) — pas de jeu d'opacité, et le rendu suit automatiquement le thème
dark :

<Canvas of={RadioStories.Disabled} />

## Formulaires et validation

Les attributs natifs (`name` surtout, pour former le groupe, mais aussi `required`,
`aria-*`…) passent en fallthrough sur l'input, pas sur le label. L'état invalide est stylé via
`:user-invalid` (validation native) ; la prop `invalid` permet de le forcer — elle pose
`aria-invalid`.

## Accessibilité

- Le libellé du slot nomme le contrôle (label englobant) ; envelopper le groupe dans un
  `<fieldset>` avec `<legend>` pour nommer la question.
- L'input est masqué via `opacity: 0` (jamais `display: none`) : il reste focusable et soumis
  au formulaire ; les flèches naviguent dans le groupe (comportement natif).
- Focus visible par anneau (`--ds-focus-ring-*`) sur la pastille, jamais supprimé.
- Les transitions respectent `prefers-reduced-motion`.
