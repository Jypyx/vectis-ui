# Breadcrumb

Fil d'Ariane data-driven : un `<nav>` + liste ordonnée entièrement piloté par la prop
`items: BreadcrumbItem[]` (`{ label, href, iconStart? }`, type exporté) — pure dérivation
de données, aucune API navigateur, SSR-safe. Chaque item est un lien ; l'item **actif** est
dérivé de `currentPath` : celui dont le `href` correspond (slash final normalisé) reste un
lien cliquable et reçoit `aria-current="page"` — pattern ARIA APG.

Les séparateurs sont des `<Icon>` décoratifs (`aria-hidden`) placés en tête de chaque item,
le premier étant masqué en CSS (`:first-child`).

## Séparateur

`separator` (défaut `chevron_right`) accepte un nom Material Symbols **ou** une URL
d'image : toute valeur contenant `.`, `/` ou `:` est traitée comme une URL (un nom Material
n'en contient jamais). Note RTL : les ligatures directionnelles ne se retournent pas
automatiquement.

## Icônes d'items

`iconStart` sur un item place une icône avant son libellé — même détection nom/URL que le
séparateur. Les icônes suivent la taille et la couleur du texte via le contexte
`--ds-icon-size`.

## Troncature

Au-delà de `maxItems` (minimum effectif : 3), la liste affiche le 1er item + un bouton
« … » + l'avant-dernier + le dernier. Le bouton ouvre un DropdownMenu listant uniquement
les items masqués, rendus en vrais liens (`<a role="menuitem">`). Clavier : flèches pour
naviguer, Échap referme et rend le focus au déclencheur.

## Accessibilité

- `<nav aria-label="Fil d'Ariane">` (personnalisable via `label`) + liste ordonnée : les
  lecteurs d'écran annoncent la navigation et la position de chaque segment.
- L'item actif reste un lien avec `aria-current="page"` — il demeure atteignable et
  identifiable (pattern APG).
- Les séparateurs sont purement décoratifs (`aria-hidden`), jamais annoncés.
- Le bouton d'ellipsis a un libellé explicite (`ellipsisLabel`, « Afficher les pages
  intermédiaires » par défaut) et son menu suit le pattern ARIA menu (roving focus).
- La police Material Symbols est chargée par le consommateur — prévoir des noms d'icônes
  avec repli acceptable (l'icône est décorative, le libellé porte le sens).
