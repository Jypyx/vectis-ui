# Button

Bouton d'action construit sur le `<button>` natif (focus, clavier et désactivation gratuits) —
ou rendu en lien `<a>` via la prop `href`. Aucun JavaScript de comportement, à une exception
près : le pont « lien inerte » (voir [Lien](#lien)).

## Variants et tones

Cinq variants (`solid`, `outline`, `ghost`, `elevated`, `tonal`) croisés avec cinq tones
(`accent`, `neutral`, `danger`, `success`, `warning`). Les tones ne définissent que des
variables CSS locales (`--_bg-solid`, `--_text-tinted`…) que les variants consomment : toute
combinaison est valide.

- **solid** : fond plein, action principale.
- **outline** / **ghost** : bordure teintée / texte seul, actions secondaires.
- **elevated** : surface surélevée avec ombre (style Material 3), texte teinté ; l'ombre
  monte au survol et retombe au press.
- **tonal** : fond teinté doux + texte teinté, entre solid et ghost.

## Tailles

Trois tailles (`sm` 32px, `md` 40px, `lg` 48px, via les tokens `--ds-control-height-*`). La
prop `compact` réduit la hauteur de 4px (28/36/44px) **sans toucher** au padding, à la
typographie ni à la taille des icônes.

<Canvas of={ButtonStories.Sizes} />

## Icônes

Les props `icon-start` / `icon-end` prennent un nom
[Material Symbols Rounded](https://fonts.google.com/icons) et rendent le composant `Icon` en
interne. La taille et l'axe `opsz` de l'icône suivent automatiquement la taille du bouton
(sm → 16px, md → 20px, lg → 24px). Les icônes sont décoratives (`aria-hidden`) : le nom
accessible du bouton reste son libellé.

> La police Material Symbols Rounded n'est pas embarquée dans la librairie : elle est chargée
> par l'application consommatrice (voir le README).

## Lien

Avec `href`, le composant rend un `<a>` : `type` et `disabled` natifs ne sont pas posés, les
attributs de lien (`target`, `rel`…) passent en fallthrough.

<Canvas of={ButtonStories.Link} />

Un `<a>` n'ayant pas de `disabled` natif, un lien `disabled` (ou `loading`) devient un
**lien inerte** : `href` retiré (non focusable, aucune navigation), `aria-disabled="true"`
pour les technologies d'assistance, handlers `click` filtrés. C'est le seul JavaScript de
comportement du composant.

<Canvas of={ButtonStories.DisabledLink} />

## États

`loading` désactive le bouton, affiche un spinner, pose `aria-busy` et atténue le bouton en
opacité (il garde ses couleurs) :

<Canvas of={ButtonStories.Loading} />

`disabled` bascule tous les variants sur des nuances de gris (`--ds-color-surface-muted`,
`--ds-color-text-subtle`) — pas de jeu d'opacité, et le rendu suit automatiquement le thème
dark :

<Canvas of={ButtonStories.Disabled} />

## Accessibilité

- Focus visible par anneau (`--ds-focus-ring-*`), jamais supprimé.
- Icônes décoratives : le nom accessible est toujours le libellé du slot par défaut. Pour un
  bouton à icône seule, utiliser `IconButton` (libellé `aria-label` obligatoire).
- `loading` → `aria-busy="true"` ; lien inerte → `aria-disabled="true"` sans `href`.
- Les transitions respectent `prefers-reduced-motion`.
