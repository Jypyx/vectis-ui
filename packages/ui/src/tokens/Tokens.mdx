# Tokens

Cette page est **générée depuis la source typée** (`src/tokens/`) — elle ne peut pas
diverger du code. Les composants ne consomment que les tokens **sémantiques** ;
les primitifs ne servent qu'à les définir.

Surcharge runtime : redéfinissez n'importe quelle custom property `--vectis-*` sur
`:root` ou sur un sous-arbre DOM (aucun rebuild). Dark mode : `data-theme="dark"`.

### Échelle sémantique (rôles de texte)

Chaque rôle est une recette complète (`--vectis-text-<rôle>-size/weight/leading[/tracking]`),
consommée par le composant **VTypography** et par le CSS des composants. Le rôle `control`
est technique (étiquettes de contrôles interactifs) : sa taille vient de l'échelle de
tailles des contrôles, pas d'un token propre.

<div style={{ display: 'grid', gap: 12, margin: '8px 0 24px' }}>
  {Object.entries(tokens.semantic.text)
    .filter(([, node]) => node.$value === undefined)
    .map(([role]) => (
      <div key={role} style={{ display: 'flex', alignItems: 'baseline', gap: 12 }}>
        <code style={{ ...mono, width: 140, flexShrink: 0 }}>{role}</code>
        <span
          style={{
            fontFamily: 'var(--vectis-text-family)',
            fontSize: `var(--vectis-text-${role}-size, var(--vectis-font-size-sm))`,
            fontWeight: `var(--vectis-text-${role}-weight)`,
            lineHeight: `var(--vectis-text-${role}-leading)`,
            letterSpacing: `var(--vectis-text-${role}-tracking, normal)`,
          }}
        >
          Portez ce vieux whisky au juge blond
        </span>
      </div>
    ))}
</div>

Familles sémantiques : `--vectis-text-family` (texte courant) et `--vectis-text-family-code`
(contenus code).
